# ALMAS — Финансовый Ассистент

Веб-приложение для дистанционного управления финансами нефтяной компании.  
Добыча: 1 000 т/мес · Контрагент: Буровая компания Титан

## Модули

| Модуль | Описание |
|---|---|
| Дашборд | Ключевые метрики, динамика за 5 мес, статус целей |
| Внести отчёт | Ввод доходов/расходов с автоматическим аудитом |
| Аудит | Чек-лист + алерты 3 уровней (критично / внимание / ок) |
| KPI директора | Еженедельный контроль 5 показателей |
| Оптимизация | Приоритизированные точки экономии и роста |
| Риски | Матрица рисков + Custom Instructions для Claude |

## Текущее состояние vs Цели

| Метрика | Факт | Цель | Статус |
|---|---|---|---|
| EBITDA margin | 28% | ≥35% | ✗ |
| Себестоимость/тонна | ₸59 400 | ≤₸55 000 | ✗ |
| Коэфф. расходов | 72% | ≤65% | ✗ |
| Доля Титан | 38% | ≤30% | ✗ |

**Потенциал оптимизации:** +₸4 700 000 – ₸9 500 000 / мес

## Запуск

Открыть `index.html` в браузере. Зависимостей нет — Chart.js подключён через CDN.
